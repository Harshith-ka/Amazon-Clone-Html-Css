🛍️ Amazon Clone

A simple Amazon website clone built using HTML and CSS. This project is a front-end recreation of Amazon’s homepage, designed to practice layout design, responsive styling, and UI development fundamentals.

🚀 Features

🧭 Fully responsive design for desktop and mobile devices

🖼️ Realistic layout similar to Amazon’s homepage

🎨 Clean and modern UI using pure HTML and CSS

🧩 Reusable components like navbar, product cards, and footer

💡 Beginner-friendly structure for learning front-end basics

🛠️ Technologies Used

HTML5 – for the structure

CSS3 – for styling and responsiveness

📂 Folder Structure
amazon-clone/
│
├── index.html           # Main HTML file
├── style.css            # Main stylesheet
├── /images              # Folder containing images and icons
└── README.md            # Project documentation
